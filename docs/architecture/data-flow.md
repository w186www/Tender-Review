# 数据流与溯源

1. API完成鉴权、类型/签名/大小检查，计算 SHA-256，将文件存入私有隔离对象并同事务记录文档与持久作业；状态quarantined不能下载或进入审查。
2. 独立Worker重新校验提交者权限与哈希，执行强制杀毒和受限容器内格式深检；失败留拒绝/失败状态，不能通过人工确认绕过。
3. 解析器生成章节、片段、表格与页坐标（DOCX用OOXML稳定定位），通过质量门禁和人工上下文确认后ready；原始对象始终经服务端鉴权和哈希复验下载，正文按引用加载。人工文本修订保留自动原文、复检质量并使上下文确认失效。详见ADR-0008。
4. 规则、检索和模型分析均记录输入引用、实现/配置版本和输出 Schema 版本。
5. 风险融合保留每个候选来源，不覆盖原始结果。
6. 证据校验产生独立判定，人工复核产生独立审计事件。
7. 人工确认后原子发布不可变结果快照，报告读取该版本；报告失败只重试渲染同一快照，不重新产生判断。导出时记录下载者、项目、版本和时间。

## 关键关联 ID

`request_id` 串联同步请求；`review_task_id` 串联一次审查；`run_id` 区分重跑；`node_run_id` 定位节点；`model_call_id` 定位模型调用；`finding_id` 和 `evidence_id` 支持结果追溯。
