# 安全架构

## 信任边界

- 浏览器与 API 之间：认证、CSRF/CORS、请求大小、速率和参数校验。
- API/Worker 与文件之间：恶意文件、解析器漏洞、压缩炸弹和路径穿越。
- 应用与模型/OCR 之间：数据最小化、脱敏、供应商允许列表和出站控制。
- 租户与租户之间：数据库过滤、对象鉴权、缓存键和检索索引隔离。
- 模型与工具之间：工具允许列表、服务端鉴权、Schema 和副作用审批。

## 主要威胁与控制

| 威胁 | 控制 |
|---|---|
| 文档 Prompt 注入 | 内容与指令分离、固定工具权限、输出 Schema、攻击评估集 |
| 跨租户读取 | 每层 tenant_id、行级策略、对象签名校验、越权测试 |
| 恶意文件 | 文件签名、限额、扫描、解析隔离、超时与资源上限 |
| 证据伪造 | 法规版本库、条款原文哈希、来源允许列表、Evidence Checker |
| 密钥泄露 | Secret Manager、日志裁剪、提交扫描、最小出站 |
| 成本与拒绝服务 | 网关限流、应用配额、Worker 并发、Token/OCR 预算、熔断 |
| 供应链风险 | 锁定依赖、SBOM、漏洞和许可证扫描、镜像签名 |

具体强制要求见 `docs/requirements/security.md`。
