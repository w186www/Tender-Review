# ADR-0001：以仓库内可校验资料作为开发事实源

- 状态：已接受
- 日期：2026-10-13

## 决策

正式 Word 文档继续用于评审和交付；开发以仓库内带版本的需求、ADR、OpenAPI、JSON Schema、任务和测试为事实源。聊天记录不承担长期项目状态。

## 原因

不同开发者和模型无法可靠共享完整聊天上下文，二进制 Word 也不适合逐行审查和自动验证。文本与契约可以在代码评审中显示差异，并由 CI 检查。

## 备选方案

本节为TASK-0015复查补记。仅以Word和聊天为依据易产生隐式状态与二进制差异；以代码为唯一依据又难表达验收和安全要求。因此保留Word作正式材料，以仓库契约、需求、ADR和测试作为可审查事实源。

## 后果

任何行为或接口变化都必须同步修改对应事实源。Word 与实现的差异在发布前必须消除或显式记录。
