# ADR-0002：使用 LangGraph 编排审查业务

- 状态：已接受
- 日期：2026-10-13

## 决策

LangGraph 管理审查 State、条件路由、并行汇合、Checkpoint、人工中断与恢复。任务队列管理跨进程调度、资源并发和基础设施重试。

## 原因

审查流程包含并行能力、证据门禁、人工复核和长任务恢复，需要显式状态机。把资源调度和业务编排分开可降低重复执行与状态不一致风险。

## 备选方案

本节为TASK-0015复查补记。全部逻辑放入任务队列难以表达人工中断和业务状态；手写状态机可行但需自行维护恢复协议。采用LangGraph编排业务、队列调度资源，并保持显式State与幂等边界。

## 后果

节点必须遵守 State 契约和幂等要求。禁止把 LangGraph 当作大文件存储或通用队列。
