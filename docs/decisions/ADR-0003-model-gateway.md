# ADR-0003：通过模型网关隔离供应商

- 状态：已接受
- 日期：2026-10-13

## 决策

所有 LLM 调用通过 `ModelGateway` 协议；业务代码引用用途 profile，不引用供应商和具体模型名。Embedding、Reranker 与 OCR 分别使用独立端口。

## 原因

项目需要在模型能力、合规、成本和可用性变化时平滑迁移，并支持不同环境采用不同供应商。

## 备选方案

本节为TASK-0015复查补记。节点直接调用供应商SDK实现简单但切换困难；只统一Prompt不能统一错误、预算和日志。采用协议+适配器+profile路由，并以同一合规测试约束供应商。

## 后果

新增供应商必须实现适配器并通过统一合规测试。供应商特有功能只有在协议提供可选 capability 且存在降级路径时才能使用。
