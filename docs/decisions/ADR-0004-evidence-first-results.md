# ADR-0004：最终结果实行证据门禁

- 状态：已接受
- 日期：2026-10-13

## 决策

规则和模型只能产生候选风险。Evidence Checker 校验原文定位、法规适用性、条款版本和推理强度后，才可形成可发布结论。证据不足时状态必须降级并进入人工复核。

## 原因

合规结论的主要风险不是漏写文字，而是引用不存在、法规过期、脱离项目背景或过度推断。

## 备选方案

本节为TASK-0015复查补记。LLM自行检查依据不能提供独立门禁；完全人工审查无法形成自动候选能力。采用候选能力、独立证据校验和人工复核的组合，保留不足证据状态。

## 后果

报告服务只读取已通过证据门禁和复核流程的版本。质量评估必须包含证据正确率和定位准确率。
