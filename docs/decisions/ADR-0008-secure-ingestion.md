# ADR-0008：隔离文件接入与可定位解析

- 状态：已接受
- 日期：2026-10-13
- 任务：TASK-0005

## 背景

文件是不可信输入。API不能执行长时间OCR或直接在主进程加载解析器；用户纠正上下文不能绕过恶意内容检查和解析质量门禁。

## 备选方案

1. API进程直接解析并信任模型提取字段：扩大攻击面、阻塞请求，拒绝。
2. 无网络限制的普通子进程：不能阻止读取宿主文件和网络，拒绝。
3. 隔离对象存储 + 事务内持久化解析作业 + 受限Docker解析器 + 可替换扫描/OCR端口：采用。

## 决策

API只负责鉴权、限定请求体、检测类型/签名和存储隔离文件，返回202。作业与文档同事务入库，由独立worker领取；不用FastAPI后台任务代替持久化队列。首期采用数据库作业表，后续可将调度适配到Redis，业务处理不变。

Worker重新检查租户、提交者当前权限、文件哈希，调用ClamAV INSTREAM扫描；扫描不可用、病毒库过期或检测非OK时均不能继续。PDF主动内容、附件与加密、DOCX宏/外部关系/路径穿越/压缩炸弹、超大图片和多帧输入均拒绝。格式深检也在容器内执行。

解析容器使用固定镜像ID、非root、只读根文件系统、无网络、无宿主目录挂载、无Docker socket、cap-drop ALL、no-new-privileges、CPU/内存/PID/临时空间限制；宿主控制器另限制时间、输入/输出字节并清理自己的容器。文件只通过stdin进入容器，不携带数据库/对象存储凭据。Docker控制端只由受控worker访问，API不启动解析容器。

PDF使用许可宽松的pdfplumber/pypdf/pdfium，保留页码、文字和表格坐标；DOCX使用受保护XML读取，保留原始OOXML段落/表格/行列路径，未渲染时不捏造页码。PNG/JPEG和扫描PDF经Tesseract中英文OCR端口，保留位置及置信度。每个片段关联原始文件哈希与文本哈希，正文存数据库片段，LangGraph未来仅接收引用。

对象存储提供本地开发适配器与S3适配器；本地模式只在development/test有效。对象键由服务端生成，包含租户哈希，不接受文档提供的URL或路径。下载必须经过租户/项目鉴权并复验哈希，禁止返回裸对象存储路径。

上传、解析、质量确认、上下文确认分别留状态和审计。解析失败或OCR质量不足不能静默ready，人工修正文段保留自动原文与审计并重新过质量门禁；上下文自动值、置信度、定位、人工值和理由按版本追加。确认操作仅reviewer可执行，并使用expected_version防止覆盖；恶意文件不能通过人工确认解除拒绝。

## 后果

需要显式增量迁移、对象存储、ClamAV与解析镜像。OCR通过可替换端口实现，实际中文准确率由黄金集后续验收。新文档状态和解析契约升级OpenAPI，尚无生产消费者。TASK-0005局部验收不等于M1全部生产安全/业务链路验收；队列运维、配额、备份、镜像漏洞/许可证完整门禁仍按TASK-0012/0013交付。

真实S3验收使用MinIO；公共镜像在首次CI无法获取，因此Dockerfile.minio-verification改为构建官方RELEASE.2025-09-07T16-13-09Z源码（提交01ce918d8279a20e4706b96a64396146894adee4，归档SHA256固定），Go基础镜像按摘要固定并保留AGPL许可证。此为测试服务，不将测试镜像作为生产存储选型或生产安全验收。
