# ADR-0015：离线神经检索、OCR 评测与运行来源追溯

- 状态：已接受（TASK-0018；本期授权限于离线模型、检索/OCR评测与可复现性基础设施）
- 日期：2026-10-15
- 补充：ADR-0003、ADR-0008、ADR-0013

## 备选方案

- 直接替换 CharacterEmbedding：会破坏已建立检索基线并丢失可比较的回退实现，不采用。
- 立即引入 pgvector：3120条款的精确矩阵规模很小，缺少性能证据，不采用。
- 直接把 PaddleOCR 设为默认：当前没有本机质量、资源及隔离验证结果，不采用。
- 把模型标识只写为可变名称或把调用参数留在日志外：无法复现，不采用。

## 背景

现有法规检索使用 BM25、CharacterEmbedding 与 RRF；字符向量不是神经语义向量，结果契约把当前算法身份固定为 `bm25-char-cosine-rrf-5`。法规索引有43个版本、3120个片段，其中42个版本仍未核实。发布快照不可变，效力/范围过滤与 Evidence Checker 是确定性证据门禁。

解析容器目前使用 Tesseract 中文/英文 OCR，容器网络关闭、只读、非 root、内存/进程受限。单元测试多用显式OCR替身，复杂中文扫描件尚无真实解析器黄金集。

TASK-0011 已冻结法规 publication、Skill/规则、Prompt版本及模型策略，但尚未绑定 OCR/Embedding权重、向量构建与检索参数的完整身份，也未记录 Prompt 内容哈希和逐调用配置身份。

## 决策

1. 保留 BM25、RRF 和 `CharacterEmbedding` 的既有行为，继续作为回退和对照；新增神经 Embedding 适配接口及本地 BGE-base-zh-v1.5 适配器。模型加载使用显式本地路径、固定推理配置和受控批量；缺模型时按明确策略失败或回退，不伪造向量。
2. Embedding 身份包含可信来源、不可变模型修订、权重哈希、分词器身份/哈希、维度、池化/归一化、推理库版本、精度、设备与批量设置。模型与结果不得仅靠可变标签识别。
3. 为当前3120片段优先使用本地精确余弦检索。向量制品按法规索引/发布修订、稳定片段身份与文本哈希、Embedding身份、维度/精度和索引构建版本内容寻址。增量构建只重算新增/变化片段；任何身份/维度不符均拒绝混用。向量制品独立于法规发布快照，重建不修改官方原文、修订或已发布结果。只有评测证明本地精确检索不满足资源/延迟目标时，才另提 pgvector 决策。
4. 神经召回只改变候选排序。地区、采购上下文、法律框架、版本效力、条款范围、核验截止和法规发布门禁保持在确定性检索路径；Evidence Checker 仍重新校验发布引用、原文、哈希、适用性和效力。相似度不能证明法律真实性或确定性。
5. 法规检索基准冻结候选快照、查询、标签、算法/参数及环境身份。正式相关性指标只使用可核实的法律片段标签；未核实法规不得成为确定正例。专家未确认的风险候选使用单独计数和报告，不混入准确率分母。召回质量和适用性过滤分别评价。
6. Tesseract 保持默认。真实 OCR 评测复用现有强制扫描与隔离解析流程。PaddleOCR 仅在候选镜像中评测；候选不得获得网络、宿主文件或服务秘密，需有 CPU/内存/时间/输出限制、稳定页码/坐标、超时与低质量失败关闭，并保留人工确认。没有实测或没有资源余量时不替换默认 OCR。
7. 不可变审查运行快照记录 OCR/解析身份、Embedding与向量构建身份、检索算法/top-k/RRF配置、Reranker开关/版本占位、Prompt模板/内容哈希和模型配置修订/身份。单次模型调用审计独立记录其 Prompt 哈希、实际模型/适配器与配置身份、参数、时间/延迟/用量、重试/失败或降级；审计只保存必要元数据，不保存原始招标正文或凭据。运行级身份在运行创建时冻结，不因后续配置变化而改变。
8. 本期不启用、不调用任何在线LLM供应商，不把真实招标文件或法规运行文本发送到第三方。真实用户样本必须由用户指定Git仓库外路径与使用范围；默认使用合成样本。

## 资源初估与限制

按3120片段、768维、float32估算，完整向量矩阵约为9.58 MB（不含少量制品元数据）；精确点积搜索无需数据库向量扩展。模型加载/推理是主要内存占用，必须本机实测。当前探测到 RTX 4050 Laptop GPU（6 GB显存）；任务执行时可用显存/内存会变化，不能据总容量推断可运行。

## 后果

旧Character检索结果和已发布法规/审查快照保持原身份与内容；新算法必须显式记录其独立版本。BGE/Paddle模型权重和运行缓存不提交Git，外部获取位置、依赖版本和文件哈希写入本地评测证据。任何性能和准确率结论只报告实际执行值；模型或数据无法获得时明确标为未测/阻断。

未核实法规全文、采购场景与潜在风险仍须法规专家确认。本ADR不批准法律效力推断，不等价TASK-0013或M5完整质量/安全验收。
