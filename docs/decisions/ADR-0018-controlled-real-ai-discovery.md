# ADR-0018：受控真实模型发现与可追溯检索

状态：accepted，2026-10-15；TASK-0023，依据用户本轮明确授权。

TASK-0022 的离线诊断契约不改写。本任务继承其安全解析、报告改动，通过新的服务端运行装配把真实 ModelGateway 注入正式网页 ReviewEngine。DEC-002 保持已消耗。本轮 DEC-005 使用 SQLite 原子预留，所有失败或未知请求计入额度，进程重启不重置。LLM 30 次、Embedding 200 批、总费用及未结预留 20 元为不可上调硬上限。

## 决策

在 Skills 汇合与法规检索之间新增可选独立模型发现节点；按已确认文档的稳定顺序分批覆盖，覆盖与模型响应保存为本地不可变 artifact，State 仅保存引用。模型摘录必须能映射到已发送且脱敏的真实文本；候选最终绑定完整本地原文片段，以复用原有严格 Evidence Checker 和报告引用定位。模型来源显式记录，历史规则候选的序列化和哈希兼容。模型输出无授权能力，禁止补造法条。

真实向量与查询使用同一固定百炼模型/维度。向量构建身份绑定完整法规快照与所选片段集合，小型索引准确报告覆盖度，其余片段仍可 BM25 检索。向量相似度仅参与可追溯排序，法规适用性、版本、核验和效力过滤均保留。没有有效法规时，疑点进入人工复核并保持证据不足，不能宣告违法。

本地网页真实模式只允许服务器配置的文件哈希；面试官未来上传的未知文件不继承本轮授权。密钥只从后端环境注入。日志仅记身份、哈希、用量、费用和错误类型，不记正文、密钥或完整供应商响应。

## 备选方案

仅修改语义Prompt无法产生新候选；直接SDK调用绕过网关；整库一次向量化超过本轮批次预算，均不采用。

## 后果

历史规则结果保留兼容；新模型发现每批最多输出3项优先疑点，覆盖记录并不证明风险穷尽。初始向量子集仅10个法规片段，其余保留BM25；没有有效上下文时不发送查询Embedding。详细调用、用量及实际检索状态需在验收报告披露。
