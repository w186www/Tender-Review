# DEC-009：采用现有法规库作为本版审查参考依据（2026-10-18）

状态：accepted（用户 2026-10-18 夜间指令）。
责任边界：用户是最终内容确认责任人；本决定取消“逐条人工核验后才能工程交付”的前置，不构成独立法律核验、专家签字或用户验收。

## 1. 决定

本版直接采用项目现有法规库作为审查参考依据。冻结身份：

- 清单：`config/legal/manifest.json`，SHA-256 `1cd46d8b28c8f36394003156622e4586f39932ce645309cd782c3ea8e7e98d09`
- 版本数：43；片段数：3120
- 法规索引：`69d340d65f5e9114c8a2e76f8b3b524b67f47d0cbc0088c4e01d80b7db8729fd`
- 采用政策：`config/legal/adoption-policy.json`，`policy_id=ADOPT-2026-10-18`
- 规则—法规关联：`config/legal/rule-law-bindings.json`，工程配置、逐条记录来源核对与理由

## 2. 明确区分

| 概念 | 本版行为 |
|---|---|
| 项目采用库内版本 | 是。采用政策覆盖清单中的 43 个版本，检索命中标记 `adoption_status=project_adopted`，可作为模型候选、检索参考和报告引用 |
| 独立法律核验 | 否。不改变任何版本的 `verification`、`verified_through`、核验日期或裁定人；报告明确“未做独立法律核验” |
| 专家/人工专业裁定 | 否。规则—法条关联记为 `asserted_by=engineering-config`，不是专家签字 |
| 正式可引用（独立核验）依据 | 仍仅限原 `citable_evidence`：已核验、期限内、条款和应用范围满足的命中；本版通常为 0 |
| 自动违法认定 | 禁止。结论供人工复核，不自动认定违法 |

## 3. 保留的检查

- 引用 `evidence_id` 必须来自该候选实际暴露的法规候选；
- 原文、条文、版本、来源哈希、发布/修订、项目适用条件和证据对应关系仍由服务端重核；
- 模型不得编造法条，不得用未提供内容补造依据；
- 规则—法规关联只按配置校对原文并记录映射/理由，不冒充人工专业核验；
- 旧报告、旧发布快照、历史核验记录不重写；
- 超期/未核验版本仍如实显示 `version_status=unverified` 及未确认原因，不改成 verified。

## 4. 影响

- 检索结果新增 `adopted_evidence`/`adoption_policy_id`，命中新增 `adoption_status`；
- 报告 v3 记录采用政策、采用参考数、工程配置关联数，并在参考条款上标注“项目采用库内版本（未经独立法律核验）”；
- 前端法规参考显示同样标注；
- 正式证据资格仍与 `citable_evidence` 分离，报告不得把采用参考称为已核验依据；
- 法规清单或索引变化时，采用政策必须重新生成并校验身份，否则失败关闭。
