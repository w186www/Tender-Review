# 编码规范

- Python 目标版本为 3.12；公共接口必须有类型标注。
- 领域对象不依赖 Web、数据库、队列或模型供应商 SDK。
- 时间统一保存 UTC，界面按用户时区显示；ID 使用不可猜测的稳定标识。
- 错误使用稳定错误码，对外不暴露堆栈、SQL、文件路径和秘密。
- 日志使用结构化字段并带 `request_id` 或 `review_task_id`，不得记录完整敏感正文。
- 配置通过环境和配置文件注入；禁止散落常量、供应商模型名和密钥。
- 公开函数保持单一职责；复杂分支优先拆为可测试纯函数。
- 注释解释原因、约束和风险，不复述代码。
- 数据格式先修改 `contracts/`；破坏性变化需要版本升级和 ADR。

提交建议格式：`type(scope): summary [TASK-####]`。
