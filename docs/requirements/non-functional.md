# 非功能需求

| ID | 指标 | 初始目标 |
|---|---|---|
| NFR-001 | 普通 API 延迟 | P95 小于 500 ms，不含上传、导出和异步处理。 |
| NFR-002 | 200 页文件完整审查 | 固定评估环境下 P95 小于 15 分钟。 |
| NFR-003 | 可用性 | 生产月可用性目标 99.5%，计划维护除外。 |
| NFR-004 | 恢复 | RPO 不超过 24 小时，RTO 不超过 4 小时；正式上线前按业务调整。 |
| NFR-005 | 幂等性 | 重复投递不产生重复文档、风险、报告或外部副作用。 |
| NFR-006 | 可观察性 | 请求、任务、节点、模型调用和报告可用关联 ID 串联。 |
| NFR-007 | 可替换性 | 更换 LLM 供应商不修改领域层和 LangGraph 节点协议。 |
| NFR-008 | 可复现性 | 审查结果记录输入哈希、规则、法规、Prompt、模型和配置版本。 |
| NFR-009 | 可维护性 | 公共接口有类型和契约；核心领域逻辑单元测试覆盖关键分支。 |
| NFR-010 | 无障碍与中文体验 | 核心界面支持键盘操作、明确状态与中文错误提示。 |
| NFR-011 | 成本控制 | 每租户和任务有 Token/OCR 预算，超限时停止、排队或按策略降级。 |
| NFR-012 | 数据可携带 | 项目元数据、审查结果、证据和审计信息可按授权导出。 |
