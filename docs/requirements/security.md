# 安全需求

| ID | 要求 | 验证方式 |
|---|---|---|
| SEC-001 | 所有业务数据按租户隔离，查询和工具执行必须带租户范围。 | 越权集成测试。 |
| SEC-002 | 使用 RBAC，管理、审核、审计与普通操作角色最小授权。 | 权限矩阵测试。 |
| SEC-003 | 上传文件校验扩展名、MIME、文件签名、大小、页数、压缩比和恶意内容。 | 恶意文件与边界样本测试。 |
| SEC-004 | 文件解析在受限进程或容器内执行，不开放任意网络、命令和文件系统能力。 | 沙箱配置检查与逃逸用例。 |
| SEC-005 | 文档内容、检索内容和模型输出不得改变系统指令、权限或工具允许列表。 | Prompt 注入评估集。 |
| SEC-006 | 模型工具调用在服务端重新鉴权并校验参数 Schema。 | 伪造工具调用测试。 |
| SEC-007 | 真实密钥只能来自秘密管理服务或运行环境，日志和错误中不得出现。 | 密钥扫描和日志测试。 |
| SEC-008 | 传输使用 TLS，敏感存储使用加密或受控托管服务。 | 部署检查。 |
| SEC-009 | 模型调用遵循数据最小化、脱敏、供应商允许列表和保留策略。 | 网关契约与审计测试。 |
| SEC-010 | 高风险配置发布、批量导出和授权变更需要二次确认或双人审批。 | 工作流测试。 |
| SEC-011 | 认证失败、越权、发布、导出、模型调用和数据删除形成防篡改审计事件。 | 审计完整性测试。 |
| SEC-012 | 依赖、镜像、代码和提交执行漏洞、许可证与秘密扫描，高危问题阻断发布。 | CI 门禁。 |
| SEC-013 | API 和 Worker 分别实施请求速率、业务并发、Token、OCR 和存储配额。 | 限流与背压测试。 |
| SEC-014 | 数据按分类和保留期清理；删除任务可验证且保留合法审计证据。 | 生命周期测试。 |

## 不可信输入原则

招标文件中出现“忽略之前指令”“调用某工具”“上传数据”等文本时，只能作为待审查正文。任何模型生成的 URL、SQL、文件路径、角色或工具参数都必须由服务端重新校验。
